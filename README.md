## 📄 About the Project / Sobre o Projeto

**[English]**

This repository hosts the official landing page for **Hyperion Cybersecurity in Brazil**.

- Secure Software Development Life Cycle (S-SDLC)
- Vulnerability Management

## 🔒 Security Posture

A interface é deliberadamente simples e não processa dados sensíveis no navegador.

Boas práticas aplicadas incluem:

- links externos com noopener;
- HTML sem dependência de frameworks pesados;
- separação clara entre apresentação e funcionalidades de projetos externos;
- escopo documentado como **landing page estática**, não como plataforma de segurança operacional.

Isso **não** significa que o projeto seja uma plataforma de cybersecurity pronta para produção. Funcionalidades como autenticação, APIs, gestão de vulnerabilidades e armazenamento de dados exigiriam backend, controles de acesso, logging e testes próprios.
